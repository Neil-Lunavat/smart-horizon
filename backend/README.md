# Smart Horizon backend

## Run

```bash
npm install
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
npm start
```

The server listens on port `8000` by default. Set `PORT` to override it.

## CSV inference endpoint

Send a CSV as the `file` multipart form field and specify the satellite orbit
using the `orbit` field (`GEO` or `MEO`):

```bash
curl -X POST \
  -F "file=@input.csv" \
  -F "orbit=GEO" \
  http://localhost:8000/predict
```

The response is the CSV generated by `predict.py` for the selected orbit.

Set `PYTHON_BIN` if you want the server to use a different Python interpreter.

## Render deployment

Deploy this repository as a **Docker** web service. Render will detect the
`Dockerfile`; leave the Docker build command blank and use the default Docker
start command. The container installs Node, Python, NumPy, and Pandas and uses
Render's `PORT` environment variable automatically.
